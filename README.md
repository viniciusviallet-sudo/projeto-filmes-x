## 📌 Sobre o Projeto

O CinemaScore é uma plataforma web desenvolvida como parte do Curso de Segurança do Trabalho, com foco na aplicação de conceitos de interface homem-máquina, usabilidade e organização de informações. O sistema simula um agregador de críticas cinematográficas, inspirado nas plataformas IMDb e Rotten Tomatoes, permitindo a visualização, pesquisa e filtragem de filmes de forma intuitiva e responsiva.
---

## 🎯 Aplicações Práticas

*Curadoria de Conteúdo: Organização e exibição de filmes com notas, selos de qualidade e descrições resumidas.
*Pesquisa e Filtragem: Sistema de busca em tempo real e filtros por nota, Tomatômetro e lançamentos.
*Design Responsivo: Interface adaptável a dispositivos móveis, tablets e desktops.
*Experiência do Usuário (UX): Cards interativos com animações sutis, cores e ícones que remetem às plataformas de referência.

## ⚙️ Pilares e Arquitetura do Sistema

Camada	Tecnologias Utilizadas	Função Principal
Interface (Front-end)	HTML5, CSS3, JavaScript	Estrutura, estilo e interatividade da página
Estilização e Design	Flexbox, Grid, Font Awesome	Layout responsivo e ícones vetoriais
Lógica e Dados	JavaScript (Vanilla)	Gerenciamento de estado, filtros e renderização dinâmica
Conteúdo Multimídia	TMDB API (The Movie Database)	Imagens dos pôsteres dos filmes
Hospedagem	Estático (arquivo .html)	Execução local ou em servidor web simples
